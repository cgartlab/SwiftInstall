### P1 — 合规 / 可访问性
- **暗色模式实现方式**：全站用 `@media (prefers-color-scheme: dark)`，而 Argus 规则默认要求 `[data-theme="dark"]` 覆盖。**这是误报**（暗色实际已覆盖），但建议在 `docs/DESIGN-SYSTEM.md` 注明"本产品采用 `prefers-color-scheme`，非 `data-theme`"，避免后续审查误判。
- **图标按钮 `aria-label`**：多数按钮为文字按钮（自带可读文本），仅少数纯图标按钮需补；主界面图标按钮已补。页面级纯图标按钮（如若有）应补 `aria-label`。当前实测无遗漏的纯图标按钮。

### P2 — 设计 token
- **JS 里的色值**：`share.html` Canvas 绘制已改为读 CSS 变量（带 fallback 字符串），`toollists.html` 的 `TILE[]` 是**每款工具的策展色板**（数据，非组件色，保留合理）；`cmdk.js` 注入样式中的 hex 均为 `var(--x, #fallback)` 的**回退值**。以上属可接受项；若要彻底消除，可把回退值也改为引用共享 palette。
- **内联动态色**：`style="background:${tileColor(...)}"` 为**数据驱动**，非样式硬编码，保留。

### P3 — 打磨
- **魔法数字**：部分字号/间距/圆角仍是 px 字面量（未全量 token 化）。已有 `DESIGN-SYSTEM.md` 的 token 体系，建议后续把高频值逐步替换为 `--space-* / --fs-*`。
