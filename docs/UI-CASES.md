# 优秀 UI / 交互成功案例（UI Cases）

> 目标：为 SwiftInstall 的"更有趣、更现代"提供可落地的参照，而不是照搬。
> 每条 = 案例 → 提炼的模式 → 我们的现状 → 可采纳的下一步。
> 来源见文末；部分为二手小结，已在标注处说明。

## 1. Raycast —— 键盘优先的命令栏

- **模式**：`⌘K/⌘Space` 唤起；输入即模糊搜索；结果**按相关性排序**并分组；`↑↓` 选择、`↵` 执行、`Esc` 关闭；高频面板**刻意不做开合动画**（避免拖慢肌肉记忆）；每个结果右侧露出快捷键；两级动作（直接执行 / `⌘K` 展开更多）。
- **我们现状**：已有全站 `⌘K` 命令面板（自注入 `cmdk.js`）、`↑↓/↵/Esc`、无开合动画（符合高频原则）。
- **下一步（本轮已做）**：把简单子串过滤升级为**模糊排序**（标题子串优先，其次子序列匹配；描述命中降权），更接近 Raycast 手感。

## 2. Linear —— 极简、快、专注

- **模式**：信息密度高但画面安静；**光学字号**与克制的字重层级；极淡渐变/模糊做深度而非装饰；过渡 **120–180ms**、缓动克制；几乎每个动作都有键盘快捷键和命令菜单。
- **我们现状**：纸墨风 + serif 标题 + 发丝线；动效 token `120/200/320/520ms` + `cubic-bezier(.22,.61,.36,1)`；`⌘K` 全站。
- **下一步**：为主要行/卡片补齐**键盘可达**（`:focus-visible` 已加）；给高频列表再加"j/k 上下、Enter 打开"的 vim 式导航（可选）。

## 3. Apple Liquid Glass（WWDC 2025）—— 折射而非模糊

- **模式（关键）**：
  1. **玻璃是"材质"不是"模糊"**：经典 glassmorphism 把背景糊到看不清；Liquid Glass 让背景保持清晰、只在**边缘按光学折射**（Snell 定律 + 位移贴图 `feDisplacementMap`），像一片真实的透镜。
  2. **只用于"浮在富内容上的少量控件"**（搜索框、工具条、播放条、滑块）；**文字密集页/表单/表格不要用**——没有可折射的内容，只剩降低可读性。
  3. **边缘曲线即设计**：默认用**凸 squared-circle**（平滑从曲面过渡到平面），避免凹面（要采样元素外的像素）。
  4. **光是灵魂**：加一条**镜面高光边（specular rim）**，眼睛才认得出"这是玻璃"。
  5. **不是主题**：每个面都玻璃 = 没有一面像玻璃。
- **我们现状**：已采用"Liquid Glass-lite"——**只在控制/导航层**用半透明（遮罩 scrim），并做了 `prefers-reduced-transparency` 实心兜底。
- **下一步**：给顶栏/命令面板加一条**极细的镜面高光边**（1px 渐变描边），提升"现代材质感"，仍克制、仍只在控制层。

## 4. 跨案例的共性（可直接抄的原则）

- **快 > 花**：高频交互（命令、列表、悬停）几乎不要动画；慢动画只给低频仪式。
- **相关性排序**：搜索结果要按匹配度排，而不是文件顺序。
- **可读性优先**：任何"效果"（玻璃/模糊/渐变）都要先保证文字对比度 ≥ 4.5:1。
- **克制的材质**：材质/深度只在"浮起的控制层"，内容层保持安静。
- **无障碍常驻**：焦点可见、键盘可达、`reduced-motion`/`reduced-transparency` 降级。
