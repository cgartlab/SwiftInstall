# SwiftInstall 产品定位与竞争分析

> 目标：说清楚"我们凭什么超越竞争对手"，也诚实标注"还差在哪"。随产品演进更新。

## 一句话定位

**一份"活"的免费/开源软件清单：体检你的电脑 → 告诉你该装什么、该换成什么 → 带你安全地换过去 → 一键装好。**

不是又一个"批量安装器"，也不是又一个"平替目录"——而是把**发现 → 核验 → 迁移 → 安装**这条链闭起来，并用设计把它做得可信、好看。

## 与竞品的能力矩阵

| 能力 | Bundl / Packd / Macnite | CaskHub | Setapp | awesome-mac / OpenSourceAlternative | Ninite | **SwiftInstall** |
|---|---|---|---|---|---|---|
| 感知本机已装 | 部分 | 已装检测 | 否 | 否 | 否 | ✅ |
| 只收免费/开源 · 免费版够用 | 部分 | 否 | 反向（卖付费） | 部分 | 否 | ✅（编辑立场） |
| **版本核验 + 免费版够用背书** | 否 | 否 | 部分 | 否 | 否 | ✅（`verified_at` + 新鲜度） |
| **迁移指导（换软件不丢数据）** | 否 | 否 | 否 | 否 | 否 | ✅（`sis guide`，带来源） |
| AI 长尾（清单外软件） | Bundl 有 AI 选包 | 否 | 否 | 否 | 否 | ✅（`sis explain`） |
| 一键安装 | ✅ | ✅ | ✅ | 否（只目录） | ✅ | ✅（本机执行） |
| 可分享 / 导入清单 | 部分 | 否 | 否 | 静态文本 | 否 | ✅（导出/导入，加载即"活"） |
| 设计 / 体验 | 一般 | 原生精致 | 精致 | 文本/朴素 | 朴素 | ✅（《Cabinet》编辑风） |
| 跨平台 | Mac 为主 | Mac | Mac | 多样 | Windows | ✅（macOS + Windows） |
| 软件目录规模 | 数千 | 数千 | 300+ | 数千~上万 | 数百 | ⚠️ 精选 4 份 / 85 项 |

**结论**：单看"目录规模 / 一键装"，我们不占优；但在"**可信的免费策展 + 版本核验 + 迁移指导 + 设计体验**"这条组合赛道上，主流竞品都没有同时做到。

## 我们赢在哪（护城河）

1. **可信策展 + 新鲜度**：每项标注授权、免费版是否够用、核对日期与来源；`sis toollist verify` / `sis doctor` 让"过期资料"可被看见、可维护。这是通用 AI 与静态清单给不了的。
2. **迁移指导（独家）**：竞品止步于"推荐"，我们给"怎么安全换过去"的分步手册（数据保真 + 来源 URL，只读不代办）。这是最难抄的慢资产。
3. **设计/体验**：编辑风（骨纸/铁墨/氧化绿），"浏览一份好书单"本身就好用好看——这是设计师/创作者用户的信任入口。
4. **闭环**：发现（`audit`/`toollist`/`explain`）→ 迁移（`guide`）→ 执行（`install`/GUI），一条链。

## 还差在哪（诚实清单）

- **目录广度**：85 项 vs 竞品数千。下一步：按主题持续扩清单（隐私安全、摄影、学生…），用"深度"换"规模"。
- **安装执行的丝滑度**：目标克隆式"选中即装"体验（当前主 GUI 已有，但清单页未直接连安装）。
- **社区与数据飞轮**：迁移配方与真实评价的 UGC 尚未上线（早期可先做"迁移后贡献配方"）。
- **真实 LLM 端到端**：本地已有 mock 全链路测试；需在有 key 的环境做一次真机验收。

## 目标用户与场景

- **主**：中文 Mac 用户里的**设计师 / 开发者 / 内容创作者 / 刚上手的新手**。
- 场景：新机到手、想从付费软件"省钱换免费"、被订阅疲劳困扰、想把自己的软件栈分享给同学/同事。
- 反例（暂不主打）：企业批量 MDM/合规场景（那是 Jamf/Intune/C4B 的战场，我们不碰）。

## 北极星指标（阶段性）

- 体检 → 完成"复制安装命令/改用平替"的转化率
- `guide` 被查看 / 被成功执行的反馈数
- 清单被导出/导入（分享）次数
- 次周回访与自发传播
