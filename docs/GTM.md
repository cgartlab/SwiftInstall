# SwiftInstall 增长与获客（GTM）

> 目标：产品之外，"被看见、被相信、被传播"同样决定能否超越竞品。本文把市场调研落成可执行的获客路径。
> 一手依据：独立 Mac 开发者 Product Hunt 实操复盘（[dev.to, 2026](https://dev.to/hiyoyok/product-hunt-launch-for-an-indie-mac-app-what-i-did-and-what-happened-5d6f)）+ 前几轮竞品调研（Ninite / Setapp / Bundl / CaskHub / awesome-mac）。

## 一、核心结论（先记住三句）

1. **发布是脉冲，内容才是长期获客**："Launch day is one day. Content is forever."（上述案例作者原话）——Product Hunt 是信号弹，不是增长渠道；真正持续带来用户的是文章/搜索/社区口碑。
2. **技术向受众要"具体"与"真实"**：真实截图（非营销 mockup）、一句话具体描述（"Mac 上的 Android 文件传输，支持 MTP"胜过"无缝连接你的移动世界"）。
3. **我们的产品天生适合内容**：软件清单 / 平替 / 迁移 / 滑卡，本身就是"可截图、可录屏、可写教程"的素材——这是竞品（纯工具）不具备的内容杠杆。

## 二、渠道矩阵（按投入产出排序）

| 优先级 | 渠道 | 玩法（针对本项目） | 目标 |
|---|---|---|---|
| P0 | **内容飞轮**（少数派 / 公众号 / 小红书 / B站） | 选题模板：①《Mac 上这 10 个免费开源工具，替代你正在付费的…》②《XX 换 YY 不丢数据：一步步迁移》③《我的一台新 Mac，15 分钟配好》→ 正文/视频里嵌 `toollist` 清单与 `/swap` 滑卡录屏 | 长期获客 + 搜索/推荐流量 |
| P0 | **开源仓库 + 落地页**（GitHub） | README 真实截图 + 一句话定位 + 一键安装；争取被 awesome-mac / awesome-selfhosted 等收录（它们本身就是流量入口） | 开发者信任、自然搜索 |
| P1 | **Product Hunt / Hacker News / r/macapps** | 按下方"发布清单"执行；一次发射+多社区联动 | 首发脉冲、种子用户 |
| P1 | **软件清单即传播物** | 每份 `toollist` 可导出 YAML/生成分享图；用户把自己的"软件栈/清单"分享出去，别人加载即"活" | 自传播 |
| P2 | **分发渠道** | Homebrew tap（brew 安装）、可选上 Setapp 精选、App Store 暂不适用（我们装的是第三方软件） | 降低安装门槛 |
| P2 | **社区** | 早期只做"迁移配方 UGC"（用户贡献真实迁移经验），不做论坛 | 数据飞轮 |

## 三、Product Hunt / HN 发布清单（来自实操复盘）

- [ ] **先有能用的成品**，别拿 beta 上（除非明确标注）。
- [ ] **真实 UI 截图**，不用营销渲染图。
- [ ] **一句话具体描述**（说清"给谁、解决什么、和谁不同"）。
- [ ] **周二–周四，太平洋时间 00:01 发布**（PH 午夜重置，首几小时票数决定排名）。
- [ ] **发布当天守着评论区**（Maker 回复、答疑、感谢——算法奖励互动）。
- [ ] **同步到 Tauri/Reddit/Discord 等相关社区**，与 PH 互相导流。
- [ ] **准备后续内容**：发布后靠"我为什么做 / 怎么做"的文章续命，而非只靠当天票数。

## 四、北极星与漏斗

- **漏斗**：内容曝光 → 落地页/仓库访问 → 下载安装 → 首次体检（AHA）→ 加载/分享清单 → 回访。
- **北极星**：完成"首次体检并导出/分享一份清单"的用户数（既验证价值，又带来传播）。
- **过程指标**：star 增速、清单导出次数、`/swap` 完成决策数、内容点击率。

## 五、与产品的结合点（已具备）

- `toollist export` / 分享 YAML → 内容与传播的载体。
- `/swap` 平替滑卡 → 天然的录屏/动图素材（差异化传播点）。
- `sis audit` 首次体检的 Scan→Report 仪式 → "AHA 时刻"，适合做成短视频开场。
- `⌘K` 与编辑风界面 → 截图即可体现"设计感"，契合小红书/少数派的审美偏好。

## 六、诚实标注

- 中文「小红书/公众号 Mac 软件」类内容的**具体播放/点赞数据本轮未查到可核实的一手统计**，上述为渠道与形式判断，非量化结论。
- Product Hunt 的结论来自**单个**独立开发者复盘（Tauri/Rust Mac 工具），对本项目有参考价值但非普适定律；发布前应以自己的小规模测试为准。
