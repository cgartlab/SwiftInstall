为什么选择 SwiftInstall？

专为中国开发者打造，解决装机时最痛的那几个问题

⚡

批量安装

一个 YAML 或 TXT 文件定义你的全部软件，sis install 一键搞定，失败不中断

🔍

状态检查

sis status 扫描系统，立刻告诉你哪些已安装、哪些还缺失

🛡️

智能跳过

--skip-existing 自动识别已安装软件跳过，重复执行幂等安全

🔄

失败重试

网络不稳？内置重试机制，可配置次数与间隔，安装更可靠

🚀

国内加速

内置 USTC 镜像源切换，自动检测 v2rayN 代理，大陆用户开箱即用

📋

Dry Run

--dry-run 预览所有安装计划，不执行任何操作，心里有数再动手

快速开始

三步完成安装，从零到满血开发环境

01

安装 sis

以管理员身份打开 PowerShell，运行：

PowerShell 
irm https://raw.githubusercontent.com/cgartlab/SwiftInstall/main/install.ps1 | iex
02

创建清单文件 sis.yaml

在任意目录创建 sis.yaml，添加你需要的软件：

sis.yaml 
mirror: ustc
packages:
  - id: Microsoft.VisualStudioCode
    category: dev
  - id: Git.Git
    category: dev
  - id: 7zip.7zip
    category: utils
03

一键安装

在 sis.yaml 所在目录运行：

PowerShell 
sis install

清单格式

支持 YAML 和纯文本两种格式，随意选择你喜欢的

YAML 格式
sis.yaml 
mirror: ustc
packages:
  - id: Microsoft.VisualStudioCode
    category: dev
  - id: Git.Git
    category: dev
  - id: 7zip.7zip
    category: utils
  - id: Notion.Notion
    category: productivity
TXT 格式
sis.txt 
# dev
Microsoft.VisualStudioCode
Git.Git

# utils
7zip.7zip

# productivity
Notion.Notion

CLI 命令

简洁直观的命令行接口，记住一个 sis 就够了

$ sis install

批量安装清单中的软件包

--skip-existing --dry-run --retry
$ sis uninstall

批量卸载清单中的软件包

--dry-run
$ sis list

列出清单中所有软件包及分类

--format json
$ sis status

检查清单软件包的安装状态

--missing-only
$ sis version

显示当前版本信息
